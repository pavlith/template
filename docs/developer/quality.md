# Quality

Run the complete quality gate before releasing:

```bash
pnpm install --frozen-lockfile
pnpm bindings
pnpm check:all
pnpm desktop:build
```

check:all runs Prettier, ESLint, svelte-check and TypeScript, ast-grep, knip,
jscpd, Vitest, Go formatting, go vet and go test in that order.
Do not disable checks to make a migration pass. The checked-in bindings are
generated by the Wails CLI pinned in go.mod, not edited manually.

Frontend tests use Vitest and a mocked generated IPC module in src/test/ipc.ts.
Go tests are ordinary *_test.go files. Tests of the persistence layer do not
require a desktop session; the actual Wails GUI still requires one.

CI is configured for frontend checks, Go checks on Linux/Windows/macOS and
a Linux desktop build. Use a graphical Linux session to test startup, hot
reload, both windows, persistence, close/quit, shortcuts, tray and native
integration. Build and test the other platforms separately; a successful
compile is not a runtime test.
